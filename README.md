# 🛡️ PixelGuard AI

PixelGuard AI is a deep learning web application that detects whether an uploaded image is **Real**, **AI Generated**, or **Fake**.

Built using **PyTorch**, **ResNet18**, and **Streamlit**, the application provides a clean and interactive interface for image analysis.

---

## 🚀 Features

- Modern Streamlit UI
- Upload JPG, JPEG and PNG images
- Deep Learning based prediction
- Confidence score
- Class probability visualization
- Image metadata
- Responsive glassmorphism interface

---

## 🧠 Model

- Architecture: ResNet18
- Framework: PyTorch
- Classes:
  - AI Generated
  - Fake
  - Real

## ⚙️ Installation

Clone the repository

```bash
git clone <repository-url>
```

Move into the project

```bash
cd PixelGuardAI
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
